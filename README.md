# Exact expression for the Berry connection in the projection gauge 

[![Journal](https://img.shields.io/badge/PhysRevB-10.1103/PhysRevB.113.245106-blue)](https://doi.org/10.1103/jh1y-x9nz) [![Zenodo](https://zenodo.org/badge/DOI/10.5281/zenodo.18727385.svg)](https://doi.org/10.5281/zenodo.18727385) 

Code accompanying the paper **"Exact expression for the Berry connection in the projection gauge"** by Trey Cole and David Vanderbilt. 

## 📜 Paper
This paper has been published in Physical Review B and is available on the APS website [(Phys. Rev. B 113, 245106)](https://doi.org/10.1103/jh1y-x9nz).

The `LaTeX` source code and a PDF of each version of the manuscript can be found in the [paper](/paper) folder. 

## 💻 Results 

Results are generated using the notebooks and scripts located in the [calculations](/calculations) folder. 

The data is available at [Zenodo](https://doi.org/10.5281/zenodo.18727385).
